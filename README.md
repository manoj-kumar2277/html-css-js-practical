## 📖 Overview

This repository is a full practical-programs website built for the **HTML, CSS & JavaScript Practical Assignment**. Rather than submitting isolated snippets, every program lives on its own page inside one cohesive, browsable site — a home dashboard links out to four sections, each with its own index and a consistent, professional dark-themed design system.

Open `index.html` in any browser and everything works immediately — **no build step, no server, no dependencies.**

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/manoj-kumar2277/html-css-js-practical.git
cd html-css-js-practical

# 2. Open directly...
open index.html          # macOS
start index.html         # Windows

# ...or serve it locally
python -m http.server 8000
# then visit http://localhost:8000
```

No installation, build tools, or package manager required. 🎉
