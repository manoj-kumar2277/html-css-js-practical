Validate Email Address (Regex)

Validates whether a given string matches a standard email address pattern.

Click "Run" to see the result…
View Source Code 
function isValidEmail(email){
  const re = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  return re.test(email);
}
