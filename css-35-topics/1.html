Inline, Internal & External CSS

Three ways to attach CSS: a style attribute on one tag, a <style> block in this page, and a linked external file (1.css).

This line is styled with inline CSS (a style="" attribute).

This dashed box is styled by an internal <style> block written in this page's <head>.

This box's background comes from external.css — see the <link> tag in the page head, and the linked file 1.css next to this page.
